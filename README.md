# football-probability-analysis

React + Vite + Tailwind CSS 静态原型，主题为足球赛事胜平负概率分析。

## 启动

```bash
npm install
npm run dev
```

## 页面

- 首页：比赛列表、胜平负概率、查看分析入口
- 比赛详情页：基本信息、概率图表、近期战绩、攻防数据、历史交锋、系统结论
- 联赛页：英超、西甲、意甲、德甲、法甲、世界杯、欧冠
- 模型说明页：分析维度说明

## 数据

静态数据统一维护在 `src/data/mockData.js`，包含 `leagues`、`teams`、`matches`。
